# Student Marks Management System

## About the Project

This is a beginner-friendly C programming project created to practice basic programming concepts.

The program accepts marks for five subjects and calculates the total marks, average, grade, and pass or fail result.

## Features

- Enter student name
- Enter marks for five subjects
- Calculate total marks
- Calculate average
- Display grade
- Display pass or fail result

## Concepts Used

- Variables
- Data types
- Arrays
- Loops
- If-else statements
- Arithmetic operators
- Input and output

## Programming Language

C
